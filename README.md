# Portfolio

My minimalist portfolio website made with Astro 🚀

## Commands

```bash
pnpm dev       # dev server
pnpm build     # production build to dist/
pnpm preview   # preview the build
pnpm test      # build + node:test checks
```

Deployed with Cloudflare Pages Git integration (`pnpm build`, output `dist`).
Analytics: Cloudflare Web Analytics only, via the manual beacon in `src/layouts/Layout.astro`.
